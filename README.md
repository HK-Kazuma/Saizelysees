# Saizelysees（サイゼリーゼ）

赤・緑・白のイタリアンレストランを経営する、ドット絵×アイソメトリック視点の経営シミュレーション（PoC）。
React + CSS + JavaScript（Vite）。スマホの横画面で遊ぶ前提で、PCでも操作できます。

## 起動

```bash
npm install
npm run dev          # http://localhost:5173 （--host 付きなので同じWi-Fiのスマホからも開ける）
```

スマホで試すときは、ターミナルに表示される `Network: http://192.168.x.x:5173/` をスマホのブラウザで開き、横向きにしてください。

## ビルド

```bash
npm run build         # dist/ に出力（GitHub Pages などに置ける）
npm run build:single  # dist/index.html 1ファイルに全部入り（画像もインライン）
```

`.github/workflows/pages.yml` を入れてあるので、GitHubのリポジトリ設定で Pages のソースを「GitHub Actions」にすると、main への push で自動公開されます。

## あそびかた

1. 「！」のお客さんから注文を聞く（右の「やること」パネル、またはお客さんをタップ）
2. 「調理する」で recipe.md どおりにボタンを押す。ミスなし＝★3（売上1.25倍）
3. できた料理を配膳 → 食後にレジで会計 → 売上と経験値
4. レベルが上がると新メニューと設備が解放。ショップで設備・スタッフ・装飾・テーブル・店舗拡張を買う
5. キッチンスタッフは調理を、ホールスタッフは注文取り・配膳・会計・片付け・ドリンク交換を自動でやってくれる
6. 画面右上のパソコンアイコンから、レシピ・ショップ・店舗情報・従業員のメニューを開ける（メニュー表示中は時間が止まる）

画面をドラッグ（スマホは指1本、PCは左クリックを押しながら）すると視点を動かせます。ズームはスマホならピンチ、PCならホイール（0.6〜3倍）。壁の絵をタップすると、ドット絵にした壁画を大きく見られます。進行状況はブラウザ（localStorage）に自動保存されます。左上のロゴからリセットできます。

## ゲーム仕様

### お客さんの流れ

`入店 → 席で考える → 注文待ち（！） → 料理待ち → 食事 → 会計待ち → 退店`

- 来店間隔は店の魅力とレベルで短くなる（最短約2.5秒）。空席がないと来店しない
- 注文待ち：`45 + 魅力×1.5` 秒、料理待ち：`55 + 魅力×2 + 手順数×4` 秒。超えると怒って帰る（店員が向かっている間は待ち時間の減りが半分）
- 注文は、そのとき解放済みで必要設備が揃っているメニューからランダムに決まる
- 店長が動いている間は、お客さんをタップするか「やること」パネルから指示を出す（店長は指示を順番にこなす）

### 調理と売上

- 調理はレシピ（全39品、7カテゴリ）どおりにボタンを押すミニゲーム。ボタンにはハズレも混ざる
- ミス0回＝★3（売上×1.25）、1〜2回＝★2（×1.0）、3回以上＝★1（×0.8）。スタッフが作る料理は★2
- 売上 ＝ 料理の価格×品質倍率（10円単位に丸め）＋ ドリンクバー（1台につき ¥100×設備Lv）
- 経験値 ＝ `価格÷12×品質倍率 ＋ 2`。次のレベルまでの必要経験値は `60 × Lv^1.55`。最大 Lv30
- レベルが上がるとメニュー・設備・スタッフ・装飾・店舗拡張が解放される
- 設備の待ち時間は強化で短縮（Lv1→Lv4で約45%短縮）

### クレーマー

- お客さん1人ごとに10%の確率でクレーマーになる（同時に1人まで）。注文は取れず、放置すると帰ってしまう
- タップすると横画面の格闘ミニゲームに入る。店長（お玉）で3回当てれば撃退成功。店長の体力は3
- クレーマーは皿を投げてくる。ジャンプでよけたり、お玉で叩き落とせる
- 負けると**所持金の半分**を持っていかれる。放置して帰られた場合も同じ
- 対応中（格闘中）はゲーム内の時間が止まる

### 店舗ステージと本部評価

- 1店舗＝1ステージ。1号店は彦根、次は草津、大津の順に出店する（滋賀県の3店舗。店舗データは `src/data/stores.js`）。期間は14日で、HUDに「3/14日目」と出る
- 最終日の閉店レポートで本部評価（S/A/B/C）が出る。点数は、期間中の総売上から怒って帰った人1人につき¥500を引いたもので、目標に対する達成率で決まる（目標の数値は暫定）
- 評価のあと「◯◯に出店する」で次の店へ進む。次の店は店舗Lv1・初期所持金¥1,000から始まり、評価ランクと先行特典（これまでの1日の最高売上）に応じた開店資金が加わる
- 前の店のセーブは残して止めておく（卒業した店の自動運営はP6で作る）。店長の能力は引き継ぐ
- 最後の店（大津）は次がないので、評価のあと「つづける」で遊び続けられる

### 時間と1日の流れ

- ゲーム内に時計と日数があり、HUDに「◯日目」「時刻」が出る（夜は月アイコン）。等倍で実時間1秒＝ゲーム内2.5分、2倍速で5分
- `10:00 開店 → 21:30 ラストオーダー（新規来店なし） → 22:00 閉店 → 23:00 レポート`。閉店で店に残っているお客さんは全員帰る（会計待ちの人は先に支払う）
- 来客は時間帯で変わる：開店直後（10〜11時）・昼下がり（15〜17時）・21時以降は少なめ（来店間隔が約2.2倍）
- 外は17〜19時にかけて暗くなり、5〜7時にかけて明るくなる
- 23:00に**1日のレポート**（売上・販売数・怒って帰った人・所持金・売れた料理の個数と金額）が出る。「明日へ」を押すまで時間は止まる
- 23:00〜翌9:00は早送り（等倍で1秒＝10分、2倍速で20分）。10:00に翌日が開店する

### お店まわりと休憩室

- 店の外に歩道・道路・ガードレール・街路樹・街灯を描画。道路は最大サイズの店の外周に固定で、店を拡張すると空き地に建物が広がっていく
- 厨房の奥に休憩室（店長の机・ロッカー・テーブル・ハンガーラック・裏口）がある
- スタッフは開店1時間前（9:00）に裏口から出勤。店長は開店前は机でパソコンを見ている
- 閉店後、お客さんがいなくなって仕事が終わったスタッフは裏口から帰る

### 片付けとドリンクバー

- お客さんが食べ終わると席に食器が残り、片付けるまで次のお客さんは座れない。「やること」パネルの「片付ける」から店長が運ぶか、ホールスタッフが洗い場（厨房の壁際）まで運ぶ
- ドリンクバーを置くと、お客さんがドリンクバーを頼める（1人あたり ¥100×設備Lv）。ドリンクは使うと減り、切れるとドリンクバーの上に表示される。店員が交換するまで補充されない
- ドリンクの容量は `8 + 4×(設備Lv−1)` 杯。強化で料金と容量が上がる

### スタッフの管理（メニュー →「従業員」）

店長とホールスタッフ1人ずつ（キッチンは表示のみ）に設定できる。

- **店長の能力**：ホールと同じ5種に「調理」を足した6種を、最大Lv5まで強化できる（店のお金で買う）。調理は、自分で調理するときの設備の待ち時間が短くなる。店長の能力は会社全体のセーブに入り、次の店にも引き継がれる

- **優先業務**：会計・配膳・注文取り・ドリンク交換・片付けの優先順位を並べ替え、オン/オフできる（上にあるほど優先）。▲▼で入れ替えると、動かした業務が浮き上がり、入れ替わる業務と左右交互にずれながら位置が変わり、「シュッ」という風の効果音が鳴る。無人レジ・QRコード注文を導入済みの業務やドリンクバー未設置のときのドリンク交換は対象外になる
- **能力**：注文取り・配膳・片付け・会計・ドリンク交換を最大Lv5まで強化できる（Lv2→5の価格は ¥2,000 / ¥5,000 / ¥10,000 / ¥18,000）。注文取り・会計・ドリンク交換は作業時間が短くなり（Lv5で40%）、配膳・片付けは一度に運べる数がLvと同じだけ増える

### シフトと人件費（草津から）

- メニューの「シフト」で、1時間ごと（10時台〜21時台の12コマ）にキッチンとホールの出勤人数を決める。出勤していない人は裏口から帰り、次の出勤の時間帯にまた来る（店長は常にいる）
- 出勤している間だけ時給がかかり、閉店後のレポートが出るのと同時にまとめて払う（1時間あたり キッチン¥80／ホール¥70。数値は暫定。店がLv16以上になると10%上がる）。払えないときは所持金がマイナスになり、HUDなどで赤字と表示される。赤字の間はショップで何も買えない（売上で黒字に戻すと買える）。彦根にはシフトも人件費もない
- 人が足りない時間は、料理待ち・注文待ちが伸びて怒って帰る人が増える。人が余っている時間は人件費だけがかさむ

### 店舗情報（メニュー →「店舗情報」）

日ごとの売上・来店数・怒って帰った人数・出費の記録を、日付を切り替えながら見られる。「グラフ」タブで推移も確認できる。「指標」タブでは、直近7日の時間帯別の待ち時間ヒートマップ（お客さん1人あたりの注文待ち＋料理待ち）、選んだ日の時間帯ごとの来店・怒って帰った人数・キッチン／ホールの稼働率、人時売上高、人件費（草津〜）を見られる。従業員画面には、スタッフ1人ずつの今日の稼働率が出る。1日のレポートにも人時売上高と人件費が載る。出費は設備・スタッフの雇用・装飾・店舗拡張/テーブル・クレーマー被害に分類される。1日のレポートにも出費が載る。

| 種類 | 内容 |

### その他

- バージョン表記はタイトル画面に表示（現在 v1.1.9）
- BGMはタイトル・ゲーム中・クレーマーとの格闘中で曲が切り替わる。ゲーム中はメニューやレシピ帳などのモーダル内を含むどのボタンでも共通のクリック音が鳴る（サウンド設定の「ボタン音」でON/OFF。優先業務の▲▼だけは専用の「シュッ」音）。タイトル画面の「あそびかた」ボタンも同じ音
- レシピ帳の料理は、パスタ系（ミートパスタなど）から順にドット絵のイラストと表示を作り込んでいる最中
- 速度切り替え（2倍速）、BGMのON/OFF・音量、全画面＆横向き、ホーム画面に追加の手順説明、データリセットはメニューから
- 進行状況は localStorage に自動保存。セーブは「会社全体」（店長の能力・最高売上。`saizelysees-company-v2`）と「店舗ごと」（お金・経験値・店舗Lv・日数・設備・スタッフ・装飾・店舗サイズ・統計・日ごとの記録。`saizelysees-store-v2-<店舗ID>`）に分かれる。日ごとの記録は直近60日だけ残し、古いものは30日ぶんずつにまとめる。旧セーブ（`saizelysees-save-v1`）は初回起動時に自動で移行され、元のデータは消さずに残る
- スマホ表示は、上部ボタンやロゴまわりのUIを小さい画面向けに調整済み

## 開発者パネル（開発時のみ）

`npm run dev` のときだけ、画面左下に 🛠 ボタンが出ます。開くとゲーム内の時間が止まり、次のことができます。本番では通常は出ませんが、URL に `?fps` を付けると本番でも出ます（実機確認用の一時的な仕様）。ただし本番では、ゲームの状態を変える操作（プリセット・時刻・所持金など）は無効で、FPS表示とテーマ切り替えだけ使えます。

- 状態プリセットの適用（初期状態・Lv5/10/15/20・全開放。現在の状態は上書きされる）
- 店舗ステージの確認（最終日をS/A/B/Cなどの評価で迎える、最高売上の設定）
- レシピ単体の確認（選んだレシピのLvと必要設備だけを揃えた状態にする）
- レシピ帳に全レシピを表示するON/OFF
- 時刻の切り替え、所持金の追加、レベル +1

ファイルは `src/dev/`（`DevPanel.jsx` / `presets.js` / `devpanel.css`）にあります。

  dev/                 開発者パネル（DEV 限定）

  components/          HUD・やることパネル・調理・クレーマー対応(FightPanel)・1日のレポート(ReportPanel)・パソコンメニュー(PcMenu)・店舗情報(StoreInfo)・従業員(StaffSettings)・ショップ・レシピ帳・タイトル・設定・演出
  assets/poster.jpg    壁に飾る絵（元画像を縮小したもの）
